## 1. 엔지니어링 지식 아카이브의 지향점

전력전자 및 모터 제어 임베디드 소프트웨어 엔지니어링에서 가장 중요한 원칙은 **"견고한 이론적 수식 모델링과 실제 하드웨어 실증이 결합될 때 비로소 완성된 제어 신뢰성을 확보할 수 있다"**는 점입니다.

수식 모델링 없이 시행착오(Heuristic) 방식으로 튜닝한 제어 파라미터는 급격한 부하 변동이나 극한의 운전 영역에서 쉽게 발산합니다. 반대로 기생 성분(Parasitic L, C)과 디지털 이산화 지연(Discretization Delay)을 고려하지 않은 이상적인 이론은 현장의 가혹한 스위칭 노이즈 앞에서 무력해집니다.

본 기술 블로그는 **이론적 상태방정식 수식 유도부터 TI C2000 DSP 펌웨어 레지스터 제어 코드, PLECS 시뮬레이션 및 오실로스코프 실측 파형 검증**에 이르는 전 과정을 체계적으로 기록하는 아카이브입니다.

## 2. 핵심 연구 및 다룰 기술 분야

```
           [ Physical Modeling & State Equations ]
                             │
                             ▼
            [ PLECS / MATLAB Closed-loop Sim ]
                             │
                             ▼
         [ TI C2000 DSP (F28377D) Register C BSW ]
                             │
                             ▼
       [ High-Power HW Experiment (10kW / 16,000 RPM) ]
```

### 1) 고효율 전력변환 회로 토폴로지 (Power Electronics)
- **10kW~30kW급 EV 급속 충전기 파워 UNIT**: 3상 3레벨 Vienna 정류기 및 양방향 Full-Bridge LLC 공진형 컨버터 설계
- **직류단 중성점 전압 밸런싱**: 3레벨 인버터/정류기의 저부하 역률 개선 및 중성점 전압 편차 억제 제어
- **고전압 스위칭 서지 저감**: 변압기 누설 인덕턴스 공진 억제를 위한 R2CD 스너버 수식 모델링

### 2) 영구자석 동기전동기(PMSM/IPMSM) 정밀 제어 (Motor Control)
- **초고속 반도체 진공펌프 인버터 (16,000 RPM)**
- **센서리스 제어**: 역기전력(EEMF) 관측기 및 저속 I-f 오픈루프 기동 시퀀스
- **무정전 회생제동(Blackout Protection)**: 정전 발생 시 전동기의 회생 운동에너지를 제어하여 제어보드 전원을 1초 이상 유지하는 안전 제어 로직

### 3) 임베디드 DSP 펌웨어 아키텍처 (Embedded DSP)
- **TI C2000 계열 (TMS320F28377D)** Dual-Core 인터럽트 서비스 루틴(ISR) 최적화
- **고속 ADC 샘플링 & ePWM 동기화**: 스위칭 노이즈 회피 샘플 트리거링 기법
- **산업용 CAN 통신**: PCAN 및 EasyDSP 기반 실시간 모니터링 UI 구축

## 3. 기술 문서 작성 원칙

1. **엄밀한 수식 전개**: KaTeX ($\LaTeX$) 표기를 통해 제어 대상의 물리적 수식을 명확히 도출합니다.
2. **실전 코드 공유**: 상용 라이브러리에 의존하지 않고 C/Embedded C 기반의 레지스터 레벨 핵심 제어 루틴을 공유합니다.
3. **재현 가능한 실증**: 시뮬레이션 결과와 실제 하드웨어 측정 파형을 1:1로 비교 분석합니다.
