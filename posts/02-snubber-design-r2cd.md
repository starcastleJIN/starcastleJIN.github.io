## 1. 연구 배경: 플라이백 스위치 턴오프 서지 문제

고전압 입력 플라이백 컨버터(Flyback Converter)에서 주 스위치(MOSFET)가 턴오프될 때, 변압기의 1차측 누설 인덕턴스($L_{lk}$)에 축적된 에너지는 스위치의 기생 출력 커패시턴스($C_{oss}$)와 공진을 일으킵니다.

이로 인해 정상 상태 차단 전압($V_{in} + n V_o$)보다 훨씬 높은 **고전압 스파이크 서지(Surge Voltage)**가 스위치 양단($V_{ds}$)에 인가되며, 이는 소자의 내압 파괴 및 심각한 전자기 간섭(EMI)을 초래합니다.

$$V_{ds,peak} = V_{in} + n V_o + V_{surge}$$

기존의 일반적인 RCD 스너버는 서지 전압을 일정 수준 클램핑하지만, 다이오드 도통 시점의 급격한 전류 변화와 2차 기생 진동을 완벽히 흡수하지 못하는 한계가 존재합니다.

## 2. R2CD 스너버 토폴로지 및 상태공간 모델링

R2CD 스너버는 기존 RCD 구조에서 스너버 커패시터($C_{sn}$)와 직렬로 **추가적인 댐핑 저항($R_{d}$)**을 삽입한 구조입니다.

```
       [ Transformer Primary ] ──┬───|>|───┬───[ Rd ]───[ Csn ]───┐
                                 │  (Dsn)  │                      │
                                [SW]      [Rsn]                  [GND]
                                 │         │                      │
                                [GND]      └──────────────────────┘
```

### 1) 턴오프 과도상태 2계 미분방정식 유도

스위치가 오프되고 스너버 다이오드($D_{sn}$)가 도통하는 과도 구간에서, 누설 인덕턴스 전류 $i_{lk}(t)$와 스너버 커패시터 전압 $v_{sn}(t)$의 2계 선형 미분방정식은 다음과 같이 유도됩니다:

$$L_{lk} \frac{d^2 i_{lk}(t)}{dt^2} + R_d \frac{d i_{lk}(t)}{dt} + \frac{1}{C_{sn}} i_{lk}(t) = 0$$

고유 진동수 $\omega_0$와 감쇠비 $\zeta$는 다음과 같이 정의됩니다:

$$\omega_0 = \frac{1}{\sqrt{L_{lk} C_{sn}}}, \quad \zeta = \frac{R_d}{2} \sqrt{\frac{C_{sn}}{L_{lk}}}$$

## 3. 목적함수(Cost Function) 기반 최적 댐핑 파라미터 도출

댐핑 저항 $R_d$가 너무 작으면 부족감쇠(Under-damped)로 인해 서지 전압 진동이 지속되고, 반대로 너무 크면 과감쇠(Over-damped)로 스너버 커패시터로의 에너지 흡수가 지연되어 피크 전압이 다시 상승합니다.

따라서 **피크 서지 전압($V_{peak}$)**과 **스너버 손실($P_{loss}$)** 간의 트레이드오프를 평가하는 비용함수 $J(R_d)$를 정식화합니다:

$$J(R_d) = w_1 \left( \frac{V_{peak}(R_d) - V_{target}}{V_{target}} \right)^2 + w_2 \left( \frac{P_{loss}(R_d)}{P_{in}} \right)$$

수식적 최소화 기법을 통해 최적 감쇠비 $\zeta_{opt} \approx 0.707$을 만족하는 최적 저항값 $R_{d,opt}$를 도출하였습니다.

## 4. 56W급 하드웨어 실험 실증

400V 입력, 24V/15V 다중 출력 56W급 플라이백 컨버터 하드웨어 보드를 제작하여 오실로스코프로 스위칭 파형을 계측하였습니다.

| 항목 | 기존 RCD 스너버 | 최적 설계 R2CD 스너버 | 개선 효과 |
| :--- | :---: | :---: | :---: |
| **Peak $V_{ds}$** | 682 V | **594 V** | **88 V 저감 (12.9% ↓)** |
| **Ring Oscillation** | 4.2 주기 지속 | **0.8 주기 이내 소멸** | **고조파 노이즈 대폭 억제** |
| **스너버 소비 전력** | 2.14 W | **1.98 W** | **효율 0.6% 향상** |

실측 파형의 서지 전압 및 감쇠 시상수가 이론적 수식 모델과 95% 이상의 높은 일치도를 보임을 확인하였습니다.
