# GitHub Pages로 나만의 포트폴리오 & 기술 블로그 시작하기

안녕하세요! 이 블로그는 **GitHub Pages**를 기반으로 구축된 저만의 개인 웹 공간입니다.

개발자로서 공부한 내용, 프로젝트를 진행하며 겪은 문제 해결 과정(Troubleshooting), 그리고 기술적 고민들을 기록하기 위해 시작했습니다.

---

## 🚀 왜 GitHub Pages인가?

웹사이트나 블로그를 운영할 때 여러 플랫폼(Tistory, Velog, Medium, Notion 등)이 있지만, 개발자에게는 GitHub Pages가 다음과 같은 강력한 장점을 제공합니다.

1. **완전 무료 호스팅 (100% Free)**
   - 별도의 서버 비용, 도메인 유지비(원하는 경우 커스텀 도메인도 무료 연결 가능)가 전혀 들지 않습니다.
2. **버전 관리와 마크다운 (Git & Markdown)**
   - 평소 코딩할 때 사용하는 Git 명령어(`git commit`, `git push`) 그대로 글을 작성하고 배포할 수 있습니다.
   - 글의 수정 이력이 Git 히스토리로 영구 보존됩니다.
3. **완벽한 커스터마이징 자유도**
   - 기존 블로그 플랫폼의 템플릿 제약 없이 내가 원하는 디자인, 레이아웃, 기능을 100% 직접 구현할 수 있습니다.
4. **빠른 로딩 속도 & 무중단 안정성**
   - GitHub의 글로벌 CDN 인프라 위에서 정적 파일로 서빙되므로 매우 빠르고 안정적입니다.

---

## 🛠️ 이 사이트의 기술 구성

이 웹사이트는 불필요한 번들링이나 복잡한 빌드 과정 없이, 브라우저 표준 기술을 바탕으로 경량화되도록 설계되었습니다.

- **HTML5 & CSS3**: 시맨틱 웹 표준을 준수하는 깔끔한 마크업
- **Tailwind CSS**: 모던하고 세련된 반응형 유틸리티 스타일링
- **Vanilla JavaScript**: 외부 프레임워크 의존성 없이 빠르고 직관적인 동적 렌더링
- **Marked.js & Highlight.js**: 마크다운 실시간 파싱 및 테마별 코드 신택스 하이라이팅
- **다크 모드 & 라이트 모드**: 사용자의 눈 피로도를 덜어주는 테마 토글

앞으로 이 공간에서는 다음과 같은 내용들을 꾸준히 다룰 예정입니다.

## 💻 코드 작성 예시

개발 블로그에서 가장 중요한 것은 읽기 편한 코드 블록입니다!

```javascript
// 환영 메시지 함수 예시
function greetVisitor(name) {
  const message = `반갑습니다, ${name}님! 블로그에 오신 것을 환영합니다.`;
  console.log(message);
  return {
    status: 200,
    greeting: message,
    timestamp: new Date().toISOString()
  };
}

greetVisitor('방문자');
```
